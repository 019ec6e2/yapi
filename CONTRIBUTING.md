# Contributing

Issues and pull requests are welcome.

1. Fork and clone the repository.
2. Keep credentials and machine-generated state out of commits.
3. Run `./scripts/check.sh`.
4. Explain behavioral or dependency changes in the pull request.

Configuration should remain portable: use `$HOME`/`~` rather than usernames or absolute home-directory paths, and preserve the yazi → existing tmux Vim pane workflow.
